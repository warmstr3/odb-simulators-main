# odb-simulators
ODB Simulators

## DNP3 Simulator Containers

### Build

1. ```shell
    cd docker/dnp3-python
   ```
2. ```shell
    docker compose build
   ```

### Run

1. ```shell
    cd docker/dnp3-python
   ```
2. ```shell
    docker compose up -d
   ```
